# Veda Technology – Task 8: Random Quote Generator

## Project Overview

The Random Quote Generator is a responsive web application developed using HTML5, CSS3, and JavaScript as part of the Veda Technology Web Development Internship.

The application displays a random inspirational quote along with its author whenever the user clicks the **New Quote** button.

## Features

- Displays random inspirational quotes with their authors.
- Stores 15 quotes as objects in a JavaScript array.
- Uses `Math.random()` to select quotes randomly.
- Prevents the same quote from appearing twice consecutively.
- Copy Quote button to copy the displayed quote.
- Optional Share button to share quotes using supported device features.
- Responsive design for mobile phones, tablets, and desktops.
- Accessible buttons and status messages.
- Simple and user-friendly interface.

## Technologies Used

- **HTML5** – Structures the web page.
- **CSS3** – Provides styling, layout, colors, and responsive design.
- **JavaScript** – Implements random selection, event handling, and DOM manipulation.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or your browser.
4. Click **New Quote** to display another inspirational quote.
5. Use **Copy Quote** to copy the quote and author.
6. Use **Share** if your browser or device supports sharing.
